🔑 Configuração inicial

Para salvar os dados no GitHub, crie um token de acesso pessoal:

1. Acesse github.com → Settings

2. Role até Developer settings (no fim do menu)

3. Personal access tokens → Tokens (classic)

4. Generate new token (classic)

5. Marque a opção repo → Generate token

6. Copie o token e cole abaixo

Token inválido ou sem permissão. Verifique e tente novamente.
